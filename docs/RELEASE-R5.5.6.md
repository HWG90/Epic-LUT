# Epic LUT R5.5.6 — Pattern Exports & MDL

- Restored Pattern LUT DDS and Patch export controls.
- Matching Pattern LUTs are included with live, preset and bulk LUT exports by default.
- Added **Include Pattern LUTs in Exports** in Configuration, synced with MCM.
- Added a dedicated **MDL API-2** package alongside BSL and modular LLL.
- Player Preview keeps its default idle pose.

**Shared Lobby LUT is in testing.**

Choose **BSL** for Arsenal/HD2MM, **LLL** for Live Lua Loader R30+, or **MDL** for compatible API-2 loaders. Nexus has BSL and MDL; GitHub has all three. Enable one Epic LUT copy and turn Match Your Colors matching off.
