# Epic LUT R5.5

Your colors. Every drop.

- Fixed custom Armor, Helmet and Pattern colors reverting during hellpod, mission and ship transitions.
- More room to edit: independent Tools, Scratch and Pattern windows, plain dropdowns and consistent font-scaled padding.
- Select and paste multiple rows with clear swatch outlines; colors stay visible underneath.
- Proper text selection, clipboard shortcuts, held-key repeat and aligned HEX cursors.
- Bulk DDS export, shareable Armory presets and destination-specific LUT/Palette patches.
- Named R0-R25 bump maps, mapped by **Scarpheon**.
- Improved Player Preview, organized settings and optional MCM integration.
- **Load Debug LUT**, supplied by **Plain Furniture**.
- **Shared Lobby LUT is in testing.**

## Install

- **Epic-LUT-R5.5-LLL.zip:** Live Lua Loader / compatible MDL. Install the complete `armor_lut_editor` folder.
- **Epic-LUT-R5.5-BSL.zip:** Arsenal / HD2MM with Bingus Shared Loader v15+.

F9: Basic. F10: Advanced. Enable one Epic LUT entrypoint. Turn Match Your Colors matching off before editing the same gear. RAR imports require 7-Zip.
