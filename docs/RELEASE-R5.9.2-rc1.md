# Epic LUT R5.9.2 RC1

Release candidate for testing.

- Export several selected LUTs in one combined patch or separate patches.
- Exported LUT names now use your custom names.
- Selected exports include the matching Pattern LUTs when enabled.

Includes the R5.9.0 performance, stability and live slider fixes. Keep your presets and settings. Enable one package: BSL, LLL R30+ or API-2 MDL.

Shared Lobby LUT remains in testing. The optional Pattern layer for O-2 Heavy Operator is not included.

To test: open LUT Editor > Export, choose **Choose LUT Patches**, select the LUTs, then choose **One combined patch** or **Separate patches**. Check renamed LUT filenames and matching Pattern results. Live-game validation is still pending.
