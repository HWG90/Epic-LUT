[b]Epic [color=#F4D44C]LUT R4 Alpha[/color] [/b]lets you edit equipped armor and helmet colors live in Helldivers 2 through the Epic LUT menu, or compatible MCM when available. Pick a color, see it on your gear, and restore the originals when you want a fresh start.

LUT means [b]lookup table[/b]: the color and material data your gear uses. We're requisitioning a new paint job, not new equipment.

[b]Built on CowboyBingus's original LUT discovery and Match Your Colors foundation.[/b] Thank you, CowboyBingus, for finding the path and sharing the tools that made this possible.

[size=4][b][color=#F4D44C]WHAT'S IN THE FIELD KIT[/color][/b][/size][/size]
[list]
[*][size=6]Choose a DDS, ZIP or RAR with the Windows file picker. ZIP/RAR archives can contain supported DDS palettes or standard patch files with their sidecars. Imported patches are not installed.[/size][/*]
[*][size=6]Import / Apply comes first. Choose an imported LUT with the left dropdown. Save LUT to Palette puts it in the editor. Check Helmet and/or Armor, then Apply LUT. Assigned palettes stay active when you choose another source. Per-LUT assignments also accumulate. Save applied setup resumes active palettes on later launches.[/size][/*]
[*][size=6]The standalone LUT Editor uses a clickable pixel grid, row-based value editor, scratch color, Undo/Redo, row copy/paste, saved row presets and portable full-float DDS preset export. RAR needs installed 7-Zip. RGB editing preserves alpha. Advanced material/camo values require unlocking.[/size][/*]
[*][size=6]No armor-name lookup, kit catalogues or installed game-archive scanning. Only local live LUT bindings are used.[/size][/*]
[/list]
[size=4][b][color=#F4D44C]REQUIREMENTS & INSTALLATION[/color][/b][/size]
[list=1]
[*][size=6]Helldivers 2 on Windows and Bingus Shared Loader v15+. Native adapters currently target Steam build 25480438.[/size][/*]
[*][size=6]Close the game, import the complete ZIP through Arsenal/HD2MM, enable its BSL startup option and deploy. Keep only one Epic LUT entry enabled.[/size][/*]
[*][size=6]Launch and press F10. Use Choose DDS or ZIP..., choose a palette, refresh live LUTs, select the target and Apply. Restore before changing gear.[/size][/*]
[/list]
[size=6][b]NO PYTHON REQUIRED. NO PYTHON BUNDLED. NO SETUP SCRIPT.[/b]
Windows supplies the file picker and ZIP extraction. The short-lived worker exits after import; an open picker exits when its launching game ends. No browser is required.

This is a standalone editor. MCM integration is not included in this lean build. Top tabs replace the left navigation rail; the value pane scrolls independently and uses 10-size body/value text. Expand a row for all 23 semantic columns, sliders, typed boxes and dropdown/stepper combos.

[size=4][b][color=#F4D44C]YOUR LUT AT WORK[/color][/b][/size]
Click a grid cell to select its row and field, then edit its RGB color or explicitly unlock advanced RGBA values. Display colors clamp to 0–1; the actual finite float values are retained. Apply sends the edited palette to your selected live LUT. Saved DDS files and row presets live under %LOCALAPPDATA%\Epic LUT.

If Match Your Colors is enabled, turn its matching Off before applying. This standalone build does not change other mods’ settings. Restore Original returns the game bindings and clears saved automatic application while retaining imported work. Remove LUT also unloads the document. Reset Custom LUT resets edits to the imported palette. Saved assignments use local slots, not process pointers or guessed gear identities.

[size=4][b][color=#F4D44C]KNOWN LIMITATIONS[/color][/b][/size]
[list]
[*]23-column material LUTs only: bounded 2D RGBA16F/RGBA32F DDS, including valid MULTI-MIP files. The full-resolution level is applied. Cube, volume, array and compressed textures remain unsupported.
[*]ZIP imports support standard patches and their GPU/stream sidecars. EXR, bulk conversion and pattern/cape layouts are outside this simplified version.
[*]Surface meanings and original live dimensions are unknown. Armor/Helmet labels describe local slots, not identified equipment. Use a suitable palette for the selected LUT.
[*]The user confirmed direct ZIP importing works. The redesigned file picker and grid UI pass offline checks but still need live visual/interaction confirmation. Multiplayer visibility, mission transitions and long sessions are not comprehensively validated.
[*]Immutable replacement textures stay retained until exit, with a bounded session budget. Restoration checks ownership and does not overwrite another writer.
[/list]
