# Epic LUT R5.1

- Applied Armory presets are remembered for the next runtime, including mixed Armor and Helmet selections.
- Preserve Original Emissives is available in LUT Editor Options and stays synced with Import / Apply.
- Corrected the current-gear editor load status message.
- Reorganized source modules and standardized shared import, preset, history and preview services.

Choose **Epic-LUT-R5.1-LLL.zip** for Live Lua Loader / compatible MDL, or **Epic-LUT-R5.1-BSL.zip** for Arsenal/HD2MM with Bingus Shared Loader v15+.

F9: Basic. F10: Advanced. F6: Player Preview. Shortcuts can be rebound in Configuration. Enable one Epic LUT entrypoint; disable the older separate preview addon.

**Alpha prerelease.** Player Preview remains experimental. Close it before switching game screens.
