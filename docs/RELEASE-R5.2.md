# Epic LUT R5.2 — The Woops Update

- GitHub update checks now include prereleases and correctly compare versions such as R5.1.
- Grid paste preserves all RGBA channels, including alpha values used by camo and shader behavior.
- Export DDS is back in LUT Editor Options, with a filename field to name your export. Exports are saved in `files/exports`, with an Open Export Location button.
- LUT Editor color popups now include an editable alpha value.

**Known issue:** Player Preview remains experimental. Close it before switching game screens.

Use the LLL package for Live Lua Loader / compatible MDL, or the BSL package for Arsenal/HD2MM with Bingus Shared Loader v15+. Enable one Epic LUT entrypoint.
