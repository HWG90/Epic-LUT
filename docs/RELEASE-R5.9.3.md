# Epic LUT R5.9.3

- Fixed the Export button in Choose LUT Patches.
- Added filename options to single DDS and selected LUT patch exports.
- Added Name only for exports that just need your name and a timestamp.
- Selected LUTs can still export together or as separate patches, with matching Patterns when enabled.

Includes Shared LUT multiplayer appearances, Armor/Helmet/Cape editing, Pattern colors and roughness, Armory presets and custom-model LUT support.

## Preparing for R6

Weapon LUT editing is the big addition coming in R6: primary, secondary and support weapon colors and materials, weapon presets, and weapon LUT import/export alongside gear editing. R5 stays the maintenance branch while R6 is being finished.

The existing R6 preview is experimental. No support offered. These weapon features are not included in R5.9.3.

Keep your presets and settings. Enable one copy: BSL, LLL R30+ or API-2 MDL. MDL is Optional on Nexus; LLL is GitHub only. Shared Lobby LUT remains in testing.
