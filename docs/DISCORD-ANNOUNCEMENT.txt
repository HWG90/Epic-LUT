# EPIC LUT R5.7.1 :goose:
**STYLISH FREEDOM — Defend Freedom in Style.**

**F9** for Basic; **F10** for the full editor. **Load Current Gear** covers Armor, Helmet and Cape.

**COMPACT EDITOR & GEAR EXPORT FIX**
- Fixed the export crash and large-patch cache errors. Patches preserve verified material, mesh and kit assignments, including distinct palettes sharing a texture ID. Tested exports and the installed patch work in-game.
- Basic prioritizes all 8 regions. Buttons, grids and previews stay compact; docked Tools starts open.
- **Camo checkboxes** start unchecked. Apply patterns/colorways only to checked regions; custom tints switch to **Current / custom**.
- One **Map LUTs to Gear** dialog in Basic and Advanced. **Auto-map** follows numbered imports and repeats them across checked Armor, Helmet and Cape columns.
- Two quick **Pattern** swatches initialize below the table. The full Pattern editor opens in that same workspace with import/export and Undo/Redo.
- Armory Save/Apply uses gear checkboxes; Basic adds individual LUT checks and **Select All**. Compact gear/Pattern previews have scrollbars.
- Values commit on click-away. **Delete** resets selected cells with Undo. Preset names complete with **Tab**; Cancel works with empty names.
