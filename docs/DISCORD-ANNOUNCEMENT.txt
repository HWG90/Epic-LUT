# EPIC LUT R5.5.3 :goose:
**STYLISH FREEDOM — Defend Freedom in Style.**

Paint your Helldiver in-game. **F9** for Basic Mode; **F10** for the full LUT Editor.

**Updates since R5.2**
- Custom colors stay applied through hellpods, missions and ship transitions.
- **Cape LUTs** now use the **Armor dropdown** and regular editor controls, with an option to exclude Capes from Armor exports.
- Added **custom LUT names**—click a hash or name to rename it.
- Fixed window stacking, overlapping text, disappearing swatches/markers and unclear **Armory save errors**.
- Fixed text-caret drift and region flashes getting stuck; menu and Preview rendering pause during Alt-Tab/minimization.
- **64-row LUTs** and a separate **Pattern LUT Editor**.
- Fixed patch targeting; export LUTs, complete palettes, shareable presets or every custom DDS in one click.
- Independent **Tools, Scratch and Pattern windows**, clearer dropdowns, borders and more editing space.
- Drag selection, multi-row copy/paste, clipboard shortcuts, proper text selection and held-key repeat.
- Improved Player Preview with **Game Default rendering** and wider vertical pan.
- Named **26 bump maps**, alpha previews, RGBA tooltips and **Load Debug LUT**.
- Organized settings, optional **MCM integration**, synchronized scale, font padding and menu fixes.

**Shared Lobby LUT is in testing.**
